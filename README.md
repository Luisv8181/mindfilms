# Mind Films

A catalogue of short mental-health explainer videos by Luis Vasquez, LAPC, NCC, made with Claude.
Every frame is drawn in code, the voices and music are generated locally, and each video cites its sources on screen.

**Watch the catalogue:** https://luisv8181.github.io/mindfilms/
